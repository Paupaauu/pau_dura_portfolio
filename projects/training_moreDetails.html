Training Analytics Dashboard

End-to-end solution that turns the monthly exports of a corporate learning platform into a live, interactive dashboard: automated loading into BigQuery, SQL cleaning and matching to the workforce list, and a fast web app that replaced a Looker Studio report and refreshes with a single click.

  • ~80k module records
  • 270 courses
  • 2,800 people
  • 1 click to update

The demo uses an anonymised sample of 15 courses and ~330 people: names, emails, IDs, sites, clients, campaigns and course names are fictitious; durations, statuses and dates are real.

// how the solution works, step by step

1. Automated data ingestion()

Monthly exports from the learning platform (CSV or Excel, each a full snapshot of the month) are dropped into a shared Drive folder. One click — or a nightly trigger — reads only new or changed files, loads them into BigQuery and keeps the most recent export for each month.

2. Cleaning and business rules in SQL()

Test courses are excluded, text is normalised, durations such as “1h 20m 5s” become minutes and percentages become ratios, mixed date formats are parsed and duplicates are removed. Every rule lives in versioned SQL, so the result is reproducible.

3. Matching to the workforce list()

Each enrolment is joined to the employee list by ID and course start date, using the record valid on that date (or the closest month). Unmatched rows are flagged instead of dropped, so data-quality gaps stay visible.

4. Fast snapshot for the dashboard()

At the end of each load the data is aggregated into a compact snapshot (dictionary-encoded, gzip-compressed and cached). Opening the dashboard never queries BigQuery: it loads in seconds and all filtering and charting happens in the browser.

5. Interactive dashboard()

Two views — Courses and Agents — with KPIs, enrolment status, planned vs actual hours by month, site and line of business, a course timeline and an agent file with module-level detail. Every chart is clickable and filters the whole dashboard.

6. Usability for every team()

Multi-select filters with search, CSV and PDF exports that respect the active filters, Spanish / English / Italian, light and dark themes, and privacy-safe usage analytics.

7. Access control and notifications()

Who can view the dashboard, run updates or receive the load report is managed from a simple Google Sheet. Every load sends an email summary with the files processed and any warnings.
